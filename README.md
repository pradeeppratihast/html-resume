# About Repo
This repo belongs to the Web Dev Cohort 2026 assignment. The clean and readable structure of a simple HTML Resume page by using only semantic HTML tags.

## How to Run Repo
### Live Demo
  - For the Web Page go to [https://pradeeppratihast.github.io/html-resume/](https://pradeeppratihast.github.io/html-resume/)
### For Code
  - With Clone
    * Run the command in your commmand terminal:
      ``` git clone https://github.com/pradeeppratihast/html-resume ```
  - Without Clone
    * Go to the url [https://github.com/pradeeppratihast/html-resume](https://github.com/pradeeppratihast/html-resume)
    * Click on the `index.html` file.
      ![Screenshot for where to find index.html in repo.](./Screenshot%202026-01-28%20180558.png)
    * If you want you can also copy or download the raw file from the raw tab.
      ![Screenshot for where to find raw tab in repo.](./Screenshot%202026-01-28%20180635.png)
